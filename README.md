# Python Assignment 2

## Data Structures – List, Dictionary, Set and Conditional Statements

### About
This assignment covers the basic concepts of Python data structures and conditional statements through simple programs and examples.

### Topics Covered

**1. Lists**
- Creating lists with integer and string elements
- Adding and removing elements
- Inserting and extending lists
- Sorting elements in descending order
- Finding maximum, minimum and sum
- Accessing elements using indexing and slicing

**2. Dictionaries**
- Creating a dictionary of student marks
- Accessing student marks
- Adding a new student
- Updating existing marks
- Displaying dictionary keys, values and items

**3. Sets**
- Creating sets and understanding duplicate removal
- Understanding why sets do not support indexing or item assignment
- Performing union and intersection operations

**4. Conditional Statements**
- Using `if`, `elif` and `else`
- Accepting a score from 0 to 10
- Classifying performance as Above Average, Average or Below Average
- Validating the score range

### Tools Used
- Python 3
- Jupyter Notebook

### How to Run
1. Download or clone this repository.
2. Open `PythonAssignment2.ipynb` in Jupyter Notebook.
3. Select a Python 3 kernel.
4. Run the cells in order using `Shift + Enter`.
5. Enter a score when prompted by the performance-category program.

### File Included
- `PythonAssignment2.ipynb` – Contains the assignment programs and their outputs.

### Conclusion
This assignment provides practical experience with Python lists, dictionaries, sets and conditional statements.
